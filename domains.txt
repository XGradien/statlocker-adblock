# statlocker-adblock domain list
# -----------------------------
# Every domain below is dead-lettered to 127.0.0.1 on the local PC, which
# stops the Statlocker companion app's third-party ad stack (bidders,
# identity syncs, beacons, creatives) from loading.
#
# The Statlocker app itself, its stats, and its data endpoints are NOT
# blocked. Blocking an apex domain also covers all of its subdomains
# (Windows DNS falls back to the parent). Lines starting with # are comments.
#
# This file is updated automatically by the domain watcher
# (.github/workflows/refresh-domains.yml), which monitors Statlocker's
# public ad-surface pages and opens a pull request when new ad
# infrastructure appears. Verified 2026-10-31 against the app's live cache
# (224 observed hosts, all covered).
